# Strand Social

Strand Social is a React + Vite template for a social-first hairstyling platform. The concept combines Pinterest-style discovery and Instagram-style engagement for hairstyles, haircuts, tutorials, and color transformations.

## Included in this template

- A bold landing/feed UI for hair inspiration
- Filters for gender, hair type, hair color, porosity, and length
- Community rating stars on every style card
- Trending and "For You" style recommendation sections
- Tutorial and video-focused content blocks

## Files

- `index.html` bootstraps the Vite app
- `src/App.jsx` renders the full social hair discovery experience
- `src/main.jsx` mounts the React app
- `src/styles.css` contains the custom visual system and responsive layout
- `src/data.js` stores the mock catalog and search data

## Run locally

1. Install Node.js 20 or newer.
2. Install dependencies with `npm install`.
3. Start the dev server with `npm run dev`.

## GitHub repo idea

This template is a strong starting point for a future full-stack app with:

- user accounts
- creator uploads
- persistent likes, saves, and ratings
- personalized recommendations
